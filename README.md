# Thesis Probes

Repository for my MSc thesis on evaluating time-series–text alignment models.

## Repository structure

```
thesis-probes/
├── data/          # datasets (ignored by Git)
├── models/        # model implementations
├── probes/        # probe generation
├── results/       # experiment outputs
├── scripts/       # helper scripts
```

## Environment

- Python 3.11
- PyTorch
- NumPy
- Pandas
- SciPy
- Matplotlib
- Transformers
