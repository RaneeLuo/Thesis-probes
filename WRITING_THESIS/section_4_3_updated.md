# 4.3 RQ2 — Sensitivity to temporal order

## 4.3.1 Design

RQ2 asks whether a model uses the order of the values in a time series, or only the values themselves. Diagnostic 2 tests this by changing a signal's temporal arrangement at evaluation time and measuring how performance changes. The main intervention is shuffling, which keeps every value but destroys their order. A model that relies only on which values appear should be largely unaffected. A model that relies on order should lose performance.

A drop after shuffling is not enough on its own, for two reasons. First, a model might lose performance whenever its input is disturbed in any way. To check this, the diagnostic also applies masking, which does the opposite of shuffling: it keeps the order of the remaining points but removes some values. If shuffling hurts but masking does not, the model depends on order. If masking hurts but shuffling does not, it depends on the values.

Second, not every description needs order. A description such as "rises and then falls" becomes false when the points are shuffled. A description such as "values lie between 0 and 10" stays true. A drop on the first is expected from a model that uses order. A drop on the second must have another cause, because that description does not depend on order. The descriptions are therefore divided into order-dependent and order-invariant groups, and the two groups are compared.

The diagnostic adapts the three shuffling operations and the separate masking intervention studied by [Tan et al. (2024)](https://proceedings.neurips.cc/paper_files/paper/2024/file/6ed5bf446f59e2c6646d23058c86424b-Paper-Conference.pdf). Shuffling destroys temporal order while preserving the values, whereas masking removes some values while preserving the order of those that remain. All interventions are applied at evaluation time, with the model parameters and descriptions held fixed. Nothing is retrained: the trained model remains frozen, the descriptions remain unchanged, and only the signals provided at test time are modified. Therefore, any performance drop is attributable to the altered signal rather than to a different model or different text.

Full shuffling permutes all time points. First-half shuffling permutes only the first half. Half exchange swaps the two halves while retaining their internal order. All three preserve the exact values and length, but full shuffling randomises positions throughout the series. Masking instead deletes 20% of the values and writes a zero in their place. It preserves the positions and relative order of unmasked observations, but can alter temporal patterns and the value distribution.

Implementations respect each input format. CLaSP masks $\lfloor0.2L\rfloor$ normalised observations: 409 of 2,048 on SUSHI, but only two of 12 on TRUCE. For TRACE, its signals have several channels (variables measured at the same time), and a shared permutation is applied across all channels within the valid, non-padding portion of each signal. This preserves cross-channel alignment at each time point while destroying temporal order and is performed before TRACE’s own internal masking step. TRACE always masks 30% of its input as part of its normal protocol, chosen randomly by a seed. For a fair comparison, the unperturbed run and the perturbed run use the same random 30% pattern. So the difference between them is only the perturbation, not a different random mask. Our extra 20% mask sits on top of the standing 30%. We write "0.3+0.2" because the two overlap: some of our 20% land on points already masked, so the total is less than 50% (the record gives an effective 0.1976 additional). Calling it "20% masking" or "50% masking" would both be wrong. ChatTS fills masked positions with the mean of the surviving values, which becomes zero after standardization. Additional comparisons shuffle values within patches of 16 points, shuffle the order of those patches, or alter the numerical text prefix while preserving the original signal tensor. Appendix C provides the full implementation details.

We sort each description by asking: what would make it false? If reordering the points could make any part of the description untrue, it is order-dependent. If nothing in it can be broken by reordering, it is order-invariant.

Genuinely unclassifiable descriptions are excluded as they are ambiguous, constant signals unchanged by permutation form a separate identity-control group.

Let $\delta$ be perturbed minus original performance. The difference-in-differences is

$$
\mathrm{DiD}=\delta_{\mathrm{invariant}}-\delta_{\mathrm{dependent}}.
$$

A positive DiD does not, by itself, indicate which group changed. It may arise because performance decreased for the order-dependent group, which is the effect of interest. Alternatively, it may arise because performance increased for the order-invariant group, as occurs in the floor condition and for ChatTS on TRUCE. It may also reflect a combination of both changes. Therefore, each DiD estimate is reported together with the baseline score and performance change for each group, allowing the reader to determine which group produced the observed difference.

No TRACE description is order-invariant, so no DiD can be computed. Instead, the analysis compares how the four interventions rank against each other, separately within the length groups (V=168, V=180 and other lengths) that Section 4.2 showed to behave differently. The embedding floor, which reads each series as serialised text, has almost no retrieval capability. Its diagnostic results were therefore declared VOID in advance, and it is run as a pipeline negative control.

Retrieval uses the **strict** metric, with one paired relevant signal per query and the whole candidate pool perturbed (Section 3.4). ChatTS averages two-choice correctness over both answer orders; these are paired presentations, not independent replications. Unless specified otherwise, intervals are 95% signal-bootstrap intervals. Equivalence follows Section 3.4's implemented 90% interval rule at $\pm0.05$ in the stated metric. CLaSP repeats across three checkpoints; TRACE repeats evaluation randomisation on one checkpoint.

For CLaSP and TRACE, each caption has one correct signal. The model ranks that signal against the full candidate pool, with every candidate perturbed under the relevant condition, and MRR records the rank of the correct signal. The analysis then compares each caption’s rank before and after perturbation. ChatTS is evaluated using a binary choice task rather than retrieval ranking. It receives a signal together with two descriptions, consisting of the correct description and a fixed distractor, and selects the better match. Each question is presented twice with the option order reversed, and correctness is averaged across the two presentations. Its changes are accuracy differences, not relative MRR losses. Shared metrics and verdict rules follow Section 3.4. Unless stated otherwise, uncertainty is reported using 95% bootstrap intervals obtained by resampling signals. Signals, rather than captions, are resampled because multiple captions may refer to the same signal, and treating those captions as independent would understate uncertainty. Equivalence is assessed using the standard TOST rule: the 90% interval for the estimated change must lie entirely within a margin of $\pm 0.05$ around zero. This margin is expressed in MRR for the retrieval models and in accuracy for ChatTS. Therefore, equivalence results use 90% intervals, whereas other uncertainty estimates generally use 95% intervals. The three repetitions represent different sources of variability for CLaSP and TRACE. CLaSP uses three independently trained checkpoints with seeds 42, 43, and 44, so the repetitions capture variability across training runs. TRACE uses a single trained checkpoint evaluated with three random draws of its protocol mask using seeds 13, 14, and 15, so its repetitions capture only variability introduced during evaluation.

Full shuffling removes most of CLaSP's dependent-group MRR: 76.4–78.3% on SUSHI and 65.7–74.5% on TRUCE across checkpoints, and Recall@10 falls in each checkpoint. Half exchange is nearly as damaging as full shuffling on both datasets, even though it keeps the order within each half. Swapping the two halves is therefore almost as disruptive as destroying all order. First-half shuffling, which leaves the second half intact, is less damaging than both in every repetition. Masking has a moderate effect on SUSHI. On TRUCE its losses are small (14%, 14% and 2% of MRR across checkpoints), consistent with only two of twelve points being masked. Its interval in Table 1 includes zero. This means the loss is too small to establish firmly. It does not show that masking has no effect.

On TRUCE, CLaSP meets the pre-registered criterion: the DiD is positive in all three checkpoints. In checkpoints 43 and 44 the invariant group barely changes, so the DiD is clearly positive (+0.076 and +0.073, intervals above zero). In checkpoint 42 the DiD is close to zero (+0.002), because the invariant group falls almost as much as the dependent group (−0.064 vs −0.066). Section 4.3.3 shows that this fall comes mainly from a single caption.

For TRACE, the two main length strata rank half exchange and masking in opposite orders. With 168 valid points, half exchange is the milder intervention; with 180, it is the more damaging one. This holds in all three seeds. A single pooled result would hide it. Full shuffling removes almost all of TRACE's MRR. For all dependent queries together, the remaining MRR is still above the random-ranking level of 0.00408 in every seed. This is not shown for each stratum separately. What TRACE still uses once order is destroyed is examined in Section 4.4.

ChatTS loses accuracy on order-dependent descriptions in both datasets. On SUSHI, full shuffling lowers accuracy from 0.733 to about 0.47. This is just below the 0.5 expected from guessing, but the interval includes 0.5. The model has therefore lost most of its advantage over guessing, but it is neither shown to be worse than guessing nor shown to be at chance. On TRUCE, about two-thirds of the DiD (+0.222 of +0.335) comes from the invariant group improving. That group starts near chance (0.528) and has only 18 items, so its rise is not a reliable signal. The clearer evidence is the 0.113 decrease in the dependent group. This result is interpreted in the context of Section 4.1, which judged ChatTS's TRUCE capability to be only just sufficient for diagnostic analysis.

ChatTS reads a series in 16-point patches, so on SUSHI the two levels of order can be tested separately. Shuffling points within each patch changes accuracy by only −0.019. Its 90% interval, [−0.048, 0.011], lies inside ±0.05, so the change counts as negligible. Rearranging whole patches instead lowers accuracy by 0.219 (95% CI [−0.296, −0.141]), close to the full-shuffle loss of 0.267. ChatTS is therefore sensitive to the order of patches but not, behaviourally, to the order within them. This does not show that the model ignores within-patch order internally. TRUCE is not tested this way, since its 12-point series is shorter than one patch.

The embedding floor, whose diagnostic results were declared VOID in advance because it can barely perform the task, serves as a negative control for the pipeline. Its dependent-group change stays within the ±0.05 equivalence margin in all 24 checks (two datasets, four interventions, three perturbation draws). This is a coarse check, since the floor's baseline MRR is already low (Section 4.3.3). Even so, its small changes can combine into a misleadingly positive DiD, as shown next.

## 4.3.3 What the findings can and cannot show

**Few invariant descriptions limit the DiD.** Invariant descriptions are rare in all three datasets: 4 of 139 SUSHI test queries (2.9%, excluding the constant class), none of 2,006 TRACE descriptions, and 245 of 7,334 classified TRUCE rows (3.3%, against a registered expectation of at least 15%). Only 18 of the TRUCE invariant rows, covering 14 signals, are in the test set. Natural descriptions of time series are thus almost always about order. As a result, losses on dependent descriptions are measured far more precisely than the stability of invariant ones. The DiD intervals also treat shared signals differently across models: for CLaSP and the floor, signals are resampled separately within each group, whereas ChatTS resamples them jointly (Appendix C).

**One caption drives CLaSP's invariant loss.** For invariant descriptions, the test asks whether the change after shuffling is small enough to ignore: the whole 90% interval must lie within ±0.05 MRR. In checkpoints 43 and 44 the TRUCE invariant group passes this test. The pass says little, however. The group starts with very low MRR (0.021 and 0.024), so even losing all of it would stay within the 0.05 margin. The test could hardly have failed. Only in checkpoint 42 does the group start high enough (0.077) for a real loss to show, and there the test fails: the change is −0.064 (90% CI [−0.180, −0.005]). Most of this loss (87.1%) comes from a single caption, "The majority is flat.", which the human check had classified as invariant. After shuffling, its signal (TRUCE-synth 126) falls from rank 1 to rank 259. CLaSP therefore does not always keep invariant descriptions stable, although the result does not reveal why. The caption's classification was not changed after this result.

**ChatTS's masking results are about the signal, not about the text in its prompt.** Masking changes two things at once. It changes the signal, and it slightly shifts the two numbers, offset and scaling, that ChatTS's prompt states about the signal. A masking effect could therefore come from either. A control separated the two: it kept the signal unchanged and shifted only these two numbers, by the amount masking would. Accuracy did not change on either dataset: SUSHI −0.005 (90% CI [−0.015, 0]) and TRUCE 0.000 (90% CI [−0.025, 0.021]), each on 100 items, both well within the ±0.05 margin. The masking results in Table 1 can thus be read as effects of the signal alone. On SUSHI, masking lowers accuracy by 0.119 because values are removed from the signal. On TRUCE, masking has a negligible effect (−0.018, 90% CI [−0.035, −0.003]). The shuffling results need no such control, because moving values around leaves their offset and scaling, and hence the prompt, unchanged. The control tested only shifts of the size masking causes, not other changes to the prompt.

**A positive DiD can arise from a model with no ability.** The floor can barely perform the task, yet its TRUCE DiDs (+0.010, +0.084, +0.072 across the three shuffles) closely match CLaSP's (+0.002, +0.076, +0.073). In both models, the intervals exclude zero in two of three shuffles. Part of this resemblance is built in: the floor is evaluated on the same random shuffles as CLaSP's checkpoints (labelled 42–44). A positive DiD therefore does not, on its own, show that a model uses order.

**What makes a DiD credible is which group changed.** The two models reach similar DiDs for opposite reasons. CLaSP's DiD comes from order-dependent descriptions getting worse, as order use predicts. The floor's comes from order-invariant descriptions getting better, which order use does not predict. In shuffle 43, for example, the floor's dependent MRR falls only slightly (0.0295 to 0.0190), while its invariant MRR rises sharply (0.0711 to 0.1441). The resulting DiD of +0.0835 comes mostly from that rise. This is why every DiD in this thesis is reported with both groups' baselines and changes (Table 1).

**Small groups are fragile.** The TRUCE invariant group has only 18 queries, so a few signals can move its MRR a lot, in either direction. Without its single most influential signal, the floor's DiD in shuffle 43 drops from +0.0835 to 0.0334. The same fragility explains CLaSP's invariant loss in checkpoint 42, driven by one caption, and ChatTS's invariant rise on TRUCE. Results from these groups should be read with caution.

**A test that cannot fail says little.** The floor's dependent MRR never changes by more than 0.0105, so it passes all 24 equivalence checks. But its baseline is already below the ±0.05 margin (about 0.03 on TRUCE), so even a complete collapse would pass. The same applies to CLaSP's invariant passes in checkpoints 43 and 44. These passes show that nothing large went wrong, not that the model is stable.

**Further limits.** Shuffling and masking are not equally strong. Masking removes a minority of values, while shuffling moves all of them. A larger loss under shuffling therefore does not show that order matters more than values. In retrieval, every candidate signal is perturbed, so a rank can change because competing signals changed too. Finally, the diagnostic measures behaviour under these interventions, not what happens inside the model, and failing to detect a change does not show that none exists.

## 4.3.4 Answer to RQ2

All three models use the order of values, not only the values themselves. Full shuffling keeps every value but removes their order, and it removes most of what the models can do on order-dependent descriptions. Afterwards, CLaSP keeps about 12–21% of its above-chance performance, TRACE about 2–4%, and ChatTS at most about 9%, falling to chance on SUSHI. A shortcut based on values alone can therefore explain only a small part of the models' performance. This share is an upper limit, since some of it may come from legitimate order-free content in the descriptions, such as noise level.

The other results support this picture. For CLaSP on TRUCE, order-dependent descriptions lose more than order-invariant ones in all three checkpoints. ChatTS reacts to the order of its 16-point patches but not to the order within them. TRACE has no order-invariant descriptions, but the damage from each intervention differs by signal length. Values matter as well: on SUSHI, masking also lowers performance for both CLaSP and ChatTS. The models thus need both order and values. Values alone are not enough, but the results cannot show that order matters more than values, because shuffling and masking differ in strength.

The evidence has limits. Invariant groups are small, ChatTS's capability on TRUCE is only just sufficient for the analysis, and the floor shows that a positive DiD can arise from a model with no ability. The results also describe how the models behave when order is disturbed, not how they process it internally.

Some performance does remain after full shuffling. Section 4.4 asks what information the models still use once order is gone.
